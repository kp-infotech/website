## Scope And Rules

- This plan does not change canonicals, robots/noindex behavior, slugs, redirects, or URL structure.
- Astro renders metadata through `BaseLayout.astro`. Page routes pass `title`, `description`, `ogImage`, and `ogType`; Open Graph and Twitter metadata derive from the same title and description.
- Canonicals are generated automatically with `canonicalUrl(...)`. Non-production noindex behavior remains the existing hostname-gated script in `BaseLayout.astro`.
- Sanity production content owns `seoTitle`, `seoDescription`, `defaultSeoTitle`, `defaultSeoDescription`, and `defaultOgImage`. There are no manual Sanity fields for canonical, robots, or noindex.
- Repo-controlled fallback metadata was updated only for the hard-coded fallback used when Sanity defaults are missing. The current Sanity `siteSettings` document still overrides that fallback until the fields below are updated in Sanity.
- Recommendations avoid adding new proof points, awards, reviews, certifications, or client claims. Existing quantified case-study claims should be retained only after content-owner validation.
